# Use case based help

In the beggining I was wrestling with Git a lot. There are plenty of great resources on how git works out there, but what I needed the most was: 'I have done this and I want to do this... what I should do?'. And thats why I'm writing this page to past myself and others who are starting now and want more of an use case based help instead of bulky documentation.

Assuming there are people like me who are prone to skip long explanations and potentionaly marginal things I will all sections with explanation of `Why you should use it`.
