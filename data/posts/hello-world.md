# Hello dev world!

Hello! I'm a starting developer, currently working in Japan. I've been inspired by Shawn Wang's article about learnig in public https://www.swyx.io/learn-in-public and started this blog. 

I've just started learning [Deno](https://deno.land) so I've took the opportunity and build the blog in [Fresh](https://fresh.deno.dev), where I will keep things which I've learned so far in one place for my own reference, so I can track my progress which will make me happy but if it helps somebody else it will make me even happier.

I will write about other things which I love like hiking, learning and Japanese language as well.

Happy reading!
